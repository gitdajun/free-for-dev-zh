# CMS

* [Contentful](https://www.contentful.com/) - Headless CMS. Free for 1 user, 2 locales, 25k records, 2 roles, and 1M API calls per month.
* [DatoCMS](https://www.datocms.com/) - Free for 1 user, 1k records, 1GB assets, and 100k API calls per month.
* [Directus](https://directus.io/) - Open-source headless CMS. Free cloud tier available.
* [Hygraph](https://hygraph.com/) - Headless CMS. Free for 1k content items, 2 users, and 1M API calls per month.
* [Sanity](https://www.sanity.io/) - Headless CMS. Free for 3 users, 100k API requests, and 10GB assets per month.
* [Strapi](https://strapi.io/) - Open-source headless CMS. Free cloud tier for small projects.
