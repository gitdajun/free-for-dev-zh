> 开发者和开源作者现在有许多提供免费套餐的服务，但把它们全部找出来并做出明智选择需要时间。

这是一份 **SaaS / PaaS / IaaS** 等服务中真实提供**长期免费额度**的清单（不是短期试用）。

本仓库基于 [ripienaar/free-for-dev](https://github.com/ripienaar/free-for-dev) 整理，做了更干净的排版与中文说明，方便中文开发者快速浏览。

- 原项目由 1600+ 人通过 Pull Request 共同维护
